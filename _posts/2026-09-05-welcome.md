This is the first post on this site. To publish a new one, drop a Markdown file into
the `_posts/` directory named:

```
YYYY-MM-DD-your-title.md
```

with front matter at the top:

```yaml
---
title: "Your post title"
tags: [optional, tags]
---
```

followed by the post body in Markdown. Commit and push — GitHub Pages rebuilds the
site automatically, no build step required on your end.
